# AI World Models for Predictive Cyber Defence

SIH (Smart India Hackathon) prototype — temporal Transformer-based
World Model for network-attack forecasting.

---

## Dataset

### Reference public dataset
[CIC-IDS2018](https://www.unb.ca/cic/datasets/ids-2018.html) is the
reference public benchmark used to contextualise the project.  It
contains labelled network traffic for multiple attack families
(DoS, DDoS, BruteForce, Infiltration, Botnet, Web).

### Simulated temporal telemetry
The current training / evaluation pipeline uses a purpose-built
**synthetic temporal telemetry dataset** generated by
`src/simulate_temporal_traffic.py`.

> **Why synthetic?**  CIC-IDS2018 has a single monotone attack
> progression which causes train/val/test label leakage under a
> chronological split.  The synthetic pipeline generates **60
> independent attack campaigns** so all five stages appear in every
> chronological split.  This is explicitly a development and
> prototyping choice, not a claim of real enterprise telemetry.

Generated files:
```
data/simulated/simulated_packets.csv   — 250 000 packet events
data/simulated/simulated_flow.csv      — 250 000 flow events
```

---

## Packet + Flow Fusion

`src/build_fused_states.py` aggregates packet and flow telemetry
into **10-second network-state windows**, producing 44 numerical
features per window:

- Packet-level: count, bytes, mean/std size, TTL, TCP window, flags,
  unique IPs/ports/protocols
- Flow-level: count, bytes, duration, packet counts, byte/packet
  rates, IAT statistics, packet-length statistics, TCP flags,
  protocol diversity
- Derived: packet-to-flow ratio, bytes-per-packet, bytes-per-flow,
  SYN/ACK ratios

Output: `data/simulated/fused_network_states.csv` — 4 358 windows.

---

## Temporal Windowing & Sequence Generation

`src/build_fused_sequences.py` slides a window of length **5** over
the chronological state sequence to produce input–output pairs:

```
X        : (N, 5, 44)   — 5 historical network states
y_state  : (N, 44)      — next network state (regression target)
y_attack : (N,)         — next-window attack label (binary)
y_stage  : (N,)         — next-window attack stage (5-class)
```

Output: `data/simulated/fused_sequences.npz`

---

## Chronological Train / Validation / Test Split

`src/split_fused_sequences.py` performs a **70 / 15 / 15**
chronological split.  No shuffling.

| Split      | Sequences | Shape         |
|------------|-----------|---------------|
| Train      | 3 047     | (3047, 5, 44) |
| Validation | 652       | (652,  5, 44) |
| Test       | 654       | (654,  5, 44) |

A `StandardScaler` is fitted **only on the training data** and its
parameters (`scaler_mean`, `scaler_scale`) are saved inside the NPZ
for use during inference and World Model rollout.

All five attack stages are present in every split.

Output: `data/simulated/fused_train_val_test.npz`

## Multi-Task Prediction

The model simultaneously produces three outputs from the same
Transformer encoder:

| Head         | Task                            | Output shape |
|--------------|---------------------------------|--------------|
| `state_head` | Next network-state regression   | (44,)        |
| `attack_head`| Binary attack / benign forecast | (1,)  logit  |
| `stage_head` | 5-class attack stage forecast   | (5,)  logits |

## Autoregressive Multi-Step Rollout

`src/world_model_rollout.py` demonstrates the key World Model
capability:

```
State[t-4], State[t-3], State[t-2], State[t-1], State[t]
         |
         v
   Transformer
         |
         v
   State[t+1]   ← fed back (no ground truth used)
         |
         v
   State[t+2]  →  State[t+3]  →  State[t+4]  →  State[t+5]
```

This answers the core research question:

> *"Given the last 5 network-state windows, what is the network
> likely to look like in the next 1–5 windows?"*

Predicted states are inverse-transformed back to the original
feature scale for interpretability.

Outputs:
- `data/simulated/forecast_trajectory.csv`
- `data/simulated/forecast_states.csv`

---

## Multi-Step Rollout Evaluation

`src/evaluate_rollout.py` evaluates the autoregressive rollout across
up to 100 representative test sequences (seed=42, stratified by true
stage).  Per-horizon metrics are reported at +1 … +5.

Outputs:
- `results/rollout_metrics.csv`
- `results/rollout_predictions.csv`
- `results/predicted_stage_transitions.csv`
- `results/representative_trajectories.csv`

## MITRE ATT&CK Stage Mapping

`src/mitre_mapping.py` maps predicted stages to representative
MITRE ATT&CK techniques.

| Stage              | ATT&CK ID | Technique                  |
|--------------------|-----------|----------------------------|
| Benign             | —         | —                          |
| Reconnaissance     | T1595     | Active Scanning            |
| BruteForce         | T1110     | Brute Force                |
| LateralMovement    | T1021     | Remote Services            |
| CommandAndControl  | T1071     | Application Layer Protocol |

> **Important:** This is a *prototype stage-to-technique mapping*.
> The model predicts network-state attack stages from aggregated
> telemetry features.  Those predicted stages are then mapped to a
> representative ATT&CK technique to aid analyst interpretation.
> The model does **not** directly detect specific ATT&CK techniques
> from raw packet or flow telemetry.

---

## Explainability

`src/explain_prediction.py` implements **feature ablation sensitivity
analysis**:

1. Run the model normally → baseline prediction.
2. For each of the 44 features, replace its values across all 5
   time-steps with the standardised mean (0.0).
3. Measure the absolute change in predicted probability.
4. Rank features by descending sensitivity.

> Features with high sensitivity scores are those whose removal
> most changes the model's prediction.  Sensitivity ≠ causation.

Output: `results/feature_importance.csv`

## How to Run

### Single inference (5-step rollout)
```bash
python src/predict.py                  # uses X_test[-1]
python src/predict.py --sample 100    # uses X_test[100]
```

### Full single rollout with CSV output
```bash
python src/world_model_rollout.py
```

### Multi-step rollout evaluation (100 test sequences)
```bash
python src/evaluate_rollout.py
```

### Explainability
```bash
python src/explain_prediction.py
python src/explain_prediction.py --sample 50 --target attack
```

### Logistic Regression baseline
```bash
python src/train_logistic_baseline.py
```

### Regenerate dataset (not normally needed)
```bash
python src/simulate_temporal_traffic.py
python src/build_fused_states.py
python src/build_fused_sequences.py
python src/split_fused_sequences.py
```
